# Promise Felix portfolio

One-page portfolio with recent work, services, and a 4-step project form that sends the visitor's answers to WhatsApp.

## Edit these first (top of `app.js`)
- `whatsapp`: your number, digits only with country code (currently 447868242781)
- `socials`: add your Instagram, TikTok, X, Facebook, YouTube, GitHub links. Empty links are hidden.
- `works`: the live links for Famous Automobile and Vix Automations (use your Netlify links)
- `pagespeedKey` (optional): a free Google PageSpeed API key so the "Run quick check" button shows real speed and SEO scores. Without it, the form still works and tells the visitor you will audit by hand.

## Add a new project
Copy one `<article class="work">` block in `index.html`, then add screenshots to `assets/work/`.

## Deploy on Netlify
Drag this `portfolio` folder onto https://app.netlify.com/drop, or connect the repo with base and publish directory `portfolio`.
